## `<camera>`

`<camera>`: photos for apps on eskiu-lang/ui. An app picks one from the photo library, takes
one with the system's camera, or shows the camera live in a CameraView and captures what it
shows. Each photo comes back as a JPEG file the app can show with Image: upright, at most
2048 pixels on its longer side, in the app's cache directory (a blob: URL on the web).

### PhotoStatus

```eskiu
enum PhotoStatus { PhotoReady, PhotoCancelled, PhotoDenied, PhotoUnavailable, PhotoFailed }
```

What a Photo reports: a photo is ready, the user cancelled, the camera permission is
denied, there is no camera (a simulator), or it failed.

### Photo

```eskiu
struct Photo { int status; string path; int width; int height; }
```

A photo, or why there is none. `path` is the file (borrowed for the handler's call: copy it
to keep it), `width` and `height` its size in pixels.

### camera_read

```eskiu

```

A message on the "camera" channel as a Photo. Its path points into `payload`.

### PhotoHandler

The latest render's handler, kept in the hook's slot.

### camera_release_handler

```eskiu
void camera_release_handler(escaping fn(Photo)->void handler)
```

Frees a photo handler's closure; use_photos calls it when it replaces or drops the
handler.

### use_photos

```eskiu
void use_photos(escaping fn(Photo)->void on_photo)
```

`on_photo` gets each photo (or failure) the camera, the picker or a capture hands back while
the scope is mounted. Mount one per screen: every mounted handler gets every photo.

### camera_pick_photo

```eskiu
void camera_pick_photo()
```

The system's photo picker: the user chooses one photo, or cancels.

### camera_take_photo

```eskiu
void camera_take_photo()
```

The system's camera: the user takes one photo, or cancels. PhotoUnavailable where there is
no camera (a simulator, a desktop browser falls back to choosing a file).

### camera_capture

```eskiu
void camera_capture()
```

What the mounted CameraView shows now, as a photo.

### CameraView

```eskiu
void CameraView(Style style, bool front)
```

The camera, live, filling the box the layout gives it (cropped to it): the back camera, or
the front one when `front`. The first one mounted asks for the camera permission;
use_photos gets PhotoDenied or PhotoUnavailable when it cannot show it.
